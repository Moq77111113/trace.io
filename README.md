# trace.dev

Landing page for [Trace](https://github.com/Moq77111113/trace) — self-hostable BDD test management. Write Gherkin, run scenarios, keep the history.

**Live:** https://moq77111113.github.io/trace.io

Astro + Tailwind v4, statically built and deployed to GitHub Pages on every push to `main`.

## Develop

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # → ./dist
pnpm preview  # serve the build locally
```

Requires Node ≥ 22.12.
